# Portable-Distance-Sensor
 A compact, battery-powered distance measuring device built using an Arduino Nano and an ultrasonic sensor. It calculates and displays the distance to nearby objects, making it perfect for use in real-world scenarios like construction, DIY, or robotics.

Key Features Fully portable and rechargeable Real-time distance measurement using ultrasonic waves Display output on LCD Efficient power usage via external power bank

Technologies Used Arduino Nano HC-SR04 Ultrasonic Sensor LCD Display Power bank supply

Skills Demonstrated Embedded systems design Sensor integration Power management for portability Real-time data acquisition Practical hardware prototyping
